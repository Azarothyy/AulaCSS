Exemplo 32 - Exercício de Aplicação de Classes

Instruções

Neste Exercício você deverá praticar a aplicação de classe CSS nos elementos HTML.

Utilize as classes dispiniveis no arquivo estilos.css para modificar a aparencia dos textos abaixo.

Você devera experimentar as classes destaque, cursiva, italico, sublinhado, azul, negrito e google.

Lembre-se que é possivel utilizar mais de uma classe no mesmo elemento.

Parte 1 - Aplicando uma classe

O HTML é uma linguagem utilizada para criar a estrutura das paginas da internet.

O CSS é utilizado para definir a aparencia dos elementos, como cores, tamanhos e tipos de fontes.

Aplique uma classe diferente em cada paragrafo acima.

Parte 2 - Utilizando mais de uma classe

As classes podem ser combinadas para criar diferentes efeitoss visuais.

Por exemplo, uma palavra pode ficar azul e em negrito

Outra palavra pode ficar italica e sublinhada.

Agora escolhe outras palavras desse texto e aplique duas ou maisclasses ao mesmo tempo.

Parte 3 - Trabalhando com fontes

A escolha da fonte pode alterar completamente a aparencia de um texto.

A classe destaque utiliza uma fonte diferente e aumenta o tamanho do texto

A classe cursiva apresenta o texto com uma aparencia semelhante a escrita a mão.

A classe google possui uma fonte que pode ser personalizada pelo aluno no arquivo estilos.css.
